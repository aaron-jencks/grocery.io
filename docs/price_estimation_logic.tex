\section{Definitions}

I know this is not the correct formal definitions for predicate logic, but it's helping me layout my thoughts onto paper so that I can get the equations correct. In this case each section is a true statement and if the section statement is true then the section content equation is used. I need for a lot of predicates and variables for this:

\subsection{Variables}

\begin{itemize}
	\item $O_r$: Requested Optimization
	\item $Q_r$: Requested Quantity
	\item $U_r$: Requested Quantity Unit
	\item $V_p$: Preferred Variant
	\item $V_m$: Matched Variant
\end{itemize}

\subsection{Predicates/Functions}

\begin{itemize}
	\item $W(x)$: Variant $x$ is variable weight
	\item $ID(x)$: Returns the ID of the variant $x$
	\item $C(x)$: Unit $x$ is count/item based
	\item $Cheap(x)$: Requested optimization is cheapest quantity
	\item $Pack(x)$: Returns the pack count of the variant $x$
	\item $Net(x)$: Returns the net quantity of the variant $x$
	\item $Unit(x)$: Returns the net quantity unit of the variant $x$
	\item $ConvertUnit(x, u_x, u_t)$: Converts the quantity $x$ from unit $u_x$ to unit $u_t$
	\item $Conv(x, y)$: There exists a conversion from unit $x$ to unit $y$ and vice versa.
\end{itemize}

We can't do anything in this case. This case would arise if somebody asked for 5 apples, but nobody had stored any kind of conversion rate for a single apple before and $Unit(V_p)$ was in pounds, but $Unit(V_m)$ was in fluid ounces.
